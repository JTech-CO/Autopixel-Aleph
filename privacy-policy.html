Overview

AutoPixel-ℵ is a browser extension that automates pixel placement on wplace.live and youplace.live. It collects no personal data, makes no network requests of its own, and sends nothing anywhere. Everything it does happens inside the tab you have open.

1. Data we process

The extension stores exactly one record in chrome.storage.local, on your device:

  • Interface state — language, panel position, collapsed/expanded.
  • Calibration — measured cell size in pixels and the reference point you clicked.
  • Selected area — the grid indices of the rectangle you dragged.
  • Run settings — speed preset, colour source, fill order, delay, jitter, limit, guard toggles.

None of this identifies you. It never leaves the browser profile, and removing the extension removes it.

2. Comprehensive disclosure

  • No personally identifiable information is collected.
  • No health, financial, authentication, personal-communication, or location data is collected.
  • No browsing history or activity on other sites is read. The content script only runs on wplace.live, youplace.live and their subdomains.
  • No analytics, telemetry, advertising, or crash reporting.
  • No data is sold or transferred to third parties — there is no third party.
  • No remote code is loaded or executed. All code ships inside the extension package.

3. How it works

The extension injects a control panel and an overlay canvas into the page, and when you start a run it dispatches synthetic pointer and keyboard events at the coordinates of each cell in the area you selected — the same events the page would receive if you moved the mouse and clicked there yourself. It reads no page content, no cookies, and no site storage.

Permissions used: storage only, to remember your settings. Host access is limited to https://wplace.live/*, https://*.wplace.live/*, https://youplace.live/* and https://*.youplace.live/*.

Additional information

Automation may be against these sites' rules. Use of this extension is at your own risk and responsibility, including any consequences for your account. The author provides it for personal and educational use and is not responsible for misuse.

Questions or concerns: open an issue on the project repository.

개요 (Overview)

AutoPixel-ℵ는 wplace.live와 youplace.live에서 픽셀 찍기를 자동화하는 브라우저 확장입니다. 개인정보를 수집하지 않고, 자체적으로 네트워크 요청을 보내지 않으며, 어떤 데이터도 외부로 전송하지 않습니다. 모든 동작은 열려 있는 탭 안에서만 일어납니다.

1. 처리하는 정보 (Data We Process)

확장은 chrome.storage.local에 다음 한 건의 기록만 기기 내부에 저장합니다.

  • 인터페이스 상태 — 언어, 패널 위치, 접힘/펼침 여부
  • 보정값 — 측정된 1칸 크기(px)와 기준점 좌표
  • 선택한 구획 — 드래그로 지정한 사각형의 격자 인덱스
  • 실행 설정 — 속도 프리셋, 색상 소스, 채우기 순서, 딜레이, 지터, 최대 개수, 보호 옵션

이 정보로 사용자를 식별할 수 없습니다. 브라우저 프로필 밖으로 나가지 않으며, 확장을 삭제하면 함께 삭제됩니다.
