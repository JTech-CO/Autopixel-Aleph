# 빠른 사용법

1. 설치·업데이트 후 확장과 Wplace 탭을 한 번 새로고침합니다.
2. 공식 도안의 빌드 화면을 엽니다.
3. 픽셀 간격을 보정하고 사각형·타원·자유곡선으로 영역을 선택합니다.
4. **공식 자동**에서 **오버레이 (i)** 또는 **현재색**을 선택합니다.
5. 안전·빠름·터보 중 하나를 고르고 **시작**을 누릅니다.

안전 10, 빠름 20px/s이며 터보 목표는 오버레이 25, 현재색 30px/s입니다. 첫 연결에는 몇 초 걸릴 수 있습니다.
PNG 재첨부나 크기 입력은 필요 없습니다. 투명 칸을 건너뛰며, 동일 색 건너뛰기는 설정에 따라 적용됩니다.

실행 중 도안이 바뀌면 같은 구획을 자동 재검사합니다. 완료 후 새 도안을 열었다면 시작만 다시 누르세요. 화면을 이동·확대하지 않았다면 보정과 구획은 유지됩니다.

**공식 자동 + 오버레이 (i)**에서 **가변 채우기**를 켜면 같은 색이 이어질 때 추출을 생략합니다. 기본값은 꺼짐입니다. 터보 목표는 색 추출 구간 25px/s, 검증된 단색 구간 30px/s입니다.

현재색은 게임에서 먼저 고른 색과 같은 도안만 칠합니다. 실행 중 색이 바뀌면 중단합니다.

Alliance 도안을 읽지 못하면 닫았다 다시 여세요. 색상 확인에 실패한 칸은 칠하지 않습니다.
실행을 끝내려면 **정지**를 누릅니다.
