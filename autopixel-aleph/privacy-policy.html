Overview

AutoPixel-ℵ automates pixel placement on Wplace. The extension processes images and settings in your browser and does not send them to the developer. It includes no analytics, advertising, telemetry or automatic error reporting.

1. Settings stored on your device

The extension uses chrome.storage.local to remember:

  • Language, panel position and size, and collapsed state.
  • Cell calibration, reference point, selected cells, selection shape and add/subtract mode.
  • Speed, colour source, variable fill, comparison and skip options, fill order, timing, limits and guards.

These settings are stored in your browser profile, without Chrome sync or an extension-operated upload. They remain after closing the tab or disabling the extension. Removing the extension clears its local settings, as described in the Chrome storage documentation.

2. Images and canvas data

Official template comparison reads template pixels, screen and game-map coordinates, palette state, and loaded map or Alliance canvas data. Live overlay detection and variable fill use this data to update the selected area and reuse verified colours. Game-map coordinates are not your device's geographic location.

Optional manual comparison reads an image you select and a canvas sample. Images, pixel samples, comparison caches and runtime diagnostics are held in memory, not saved with settings or uploaded to the developer. Reloading or closing the game tab clears this temporary data. Stopping a run alone does not clear every loaded image.

On the map, comparison may temporarily enable the site's incorrect-pixel display and restore it after comparison, provided you have not changed that preference yourself.

3. Wplace access and network requests

The adapter identifies official JavaScript modules already observed on the page, reads their sources with a cache-first request and reuses validated exports. A cache miss can cause a request to the same Wplace origin. The browser may include existing site cookies with these requests; the extension does not read cookie values or account credentials. Extension logic is included in the package.

Painting sends pointer and keyboard events to Wplace. The site's own handlers may communicate actions and pixel changes to Wplace servers. The extension does not press Save or Publish. Wplace's own data handling is separate from this extension.

The only API permission is storage. Content scripts run only on https://wplace.live/* and https://*.wplace.live/*. The extension does not read browsing history or activity on other sites.

4. This policy page

This page stores your language choice in localStorage under apx-policy-lang. Clear site data for this page's origin to remove it. This is separate from extension settings and is not removed when you uninstall the extension.

The public page is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security, as explained in its Pages documentation and Privacy Statement. This page adds no analytics or advertising.

5. Contact and changes

For questions, open a project issue. Issue contents are public, so include only information you intend to share. This policy will be updated when the described data handling changes.

개요

AutoPixel-ℵ는 Wplace에서 픽셀 찍기를 자동화합니다. 이미지와 설정은 브라우저에서 처리하며 개발자에게 전송하지 않습니다. 분석, 광고, 텔레메트리 및 자동 오류 보고 기능은 포함하지 않습니다.

1. 기기에 저장하는 설정

확장은 chrome.storage.local에 다음 설정을 저장합니다.

  • 언어, 패널 위치와 크기, 접힘 상태
  • 칸 크기 보정값, 기준점, 선택한 칸, 선택 모양과 추가·빼기 모드
  • 속도, 색상 소스, 가변 채우기, 비교·건너뛰기 옵션, 채우기 순서, 입력 간격, 제한 및 보호 옵션

설정은 브라우저 프로필에 저장하며 Chrome 동기화나 확장 자체의 업로드 기능을 사용하지 않습니다. 탭을 닫거나 확장을 비활성화해도 유지됩니다. 확장을 삭제하면 해당 설정도 삭제됩니다. 자세한 내용은 Chrome 저장소 문서에서 확인할 수 있습니다.

2. 이미지와 캔버스 정보

공식 도안 비교는 도안 픽셀, 화면·게임 지도상의 좌표, 팔레트 상태, 로드된 지도 또는 Alliance 캔버스 정보를 읽습니다. 실시간 오버레이 감지와 가변 채우기는 이 정보를 이용해 선택 구획의 비교 결과를 갱신하고 검증된 색상을 재사용합니다. 게임 지도상의 좌표는 기기의 실제 위치 정보가 아닙니다.

선택 사항인 수동 비교는 사용자가 지정한 이미지와 캔버스 표본을 읽습니다. 이미지, 픽셀 표본, 비교 캐시 및 실행 진단 정보는 메모리에서 처리하며 설정에 저장하거나 개발자에게 업로드하지 않습니다. 게임 탭을 새로고침하거나 닫으면 이 임시 정보가 사라집니다. 실행을 정지하는 것만으로 불러온 이미지가 모두 지워지지는 않습니다.

지도 비교 시 사이트의 오색 표시를 잠시 켤 수 있으며, 사용자가 해당 설정을 직접 변경하지 않았다면 비교 종료 후 복원합니다.

3. Wplace 접근과 네트워크 요청

어댑터는 페이지에서 관찰된 공식 JavaScript 모듈을 찾아 캐시 우선 요청으로 소스를 읽고, 검증된 모듈을 재사용합니다. 캐시에 없으면 동일한 Wplace 출처로 네트워크 요청이 발생할 수 있습니다. 브라우저가 기존 사이트 쿠키를 요청에 포함할 수 있지만, 확장이 쿠키 값이나 계정 인증 정보를 직접 읽지는 않습니다. 확장 자체 로직은 패키지에 포함됩니다.

칠하기는 Wplace에 포인터·키보드 이벤트를 전달합니다. 사이트 자체 처리 과정에서 동작이나 픽셀 변경 정보가 Wplace 서버로 전달될 수 있습니다. 확장은 저장·게시 버튼을 누르지 않습니다. Wplace 자체의 정보 처리는 이 확장과 별개입니다.

API 권한은 storage만 사용합니다. 콘텐츠 스크립트는 https://wplace.live/* 및 https://*.wplace.live/*에서만 실행합니다. 방문 기록이나 다른 사이트의 활동은 읽지 않습니다.

4. 이 방침 페이지

이 페이지는 선택한 언어를 localStorage의 apx-policy-lang 항목에 저장합니다. 삭제하려면 이 페이지 출처의 사이트 데이터를 지우세요. 확장 설정과 별개이므로 확장을 삭제해도 이 언어 설정은 남습니다.

공개 페이지는 GitHub Pages에서 호스팅합니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록합니다. 자세한 내용은 Pages 문서와 개인정보 처리방침을 참고하세요. 이 페이지에 별도의 분석이나 광고 기능은 없습니다.
