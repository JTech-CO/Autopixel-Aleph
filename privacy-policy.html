wplace hover

Privacy Policy

Chrome Extension

Last updated: July 26, 2026 · Version 1.2.0

wplace hover is a Chrome extension that waits until the pointer remains at one location for a selected dwell time, then sends an i key event followed by two click sequences on wplace.live. This policy explains how the extension handles information.

Summary: wplace hover does not collect, sell, share, or transmit personal data. It has no analytics, advertising, telemetry, account system, or external server connection. Only extension preferences are stored locally on the user's device.

1. Information Processed

  • Pointer coordinates: The current in-page pointer position is held temporarily in memory so the extension can dispatch clicks at that location. It is never stored or transmitted.
  • Extension preferences: Enabled state, dwell time, and panel collapse state are stored with chrome.storage.local. These values contain no personal information and remain on the local device.

2. Collection, Use, and Storage

  • No personal data is collected.
  • Pointer coordinates are used only to identify the location where the synthetic click sequence should run.
  • Preferences are used only to restore the user's selected extension behavior and panel state.
  • No cookies, logs, analytics, telemetry, advertising identifiers, or cloud synchronization are used.

3. Permissions and Site Access

  • The content script runs only on https://wplace.live/* and its subdomains.
  • The only declared Chrome permission is storage, used solely for local preferences.
  • The extension observes pointer movement and relevant keyboard input on the supported site, then dispatches synthetic keyboard and mouse events.
  • It does not access browsing history, other tabs, cookies, clipboard contents, files, or account credentials.

4. Sharing and Third Parties

No information is shared with third parties. The extension contains no third-party analytics SDKs, advertising services, remote code, or network-based tracking components.

5. Retention and Deletion

Pointer coordinates exist only in memory while the page is open. Preference values remain in local extension storage until they are changed, cleared through the browser, or removed with the extension.

6. Security

Processing occurs locally in the browser. Because the extension does not transmit data, no user information is sent to an external server by the extension.

7. Policy Changes

Material changes to this policy will be reflected by updating the version and date shown at the top of this page.

8. Contact

Questions about this policy may be submitted through the Issues section of the project's GitHub repository.

wplace hover is an open-source utility for personal and educational use. Users are responsible for ensuring that their use complies with the applicable site's rules and terms.
