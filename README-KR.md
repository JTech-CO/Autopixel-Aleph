# AutoPixel-ℵ

Wplace 전용 자동 칠하기 Chrome 확장입니다.
현재 버전: **2.2.0 (Wplace update 1)**.

[English](README.md) | [빠른 사용법](사용법.md) | [변경 사항](CHANGES.md)

## 설치

1. ZIP을 풀고 chrome://extensions를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 autopixel-aleph 폴더를 선택합니다.
3. 이전 확장은 끄고 Wplace 탭을 새로고침합니다. 파일을 갱신했다면 확장도 새로고침합니다.

## 주요 기능

- 사각형·타원·자유곡선 선택과 영역 추가·빼기
- PNG 재첨부 없이 지도와 Alliance의 공식 도안 비교
- 투명 칸 건너뛰기와 선택 가능한 동일 색 건너뛰기
- 칠하기 전 색상 확인과 확인 실패 칸의 미도색 처리
- 안전 10, 빠름 20px/s와 터보의 오버레이 25, 현재색 30px/s 목표

공식 도안의 빌드 화면에서 **오버레이 (i)**와 **공식 자동**을 사용하세요.
첫 연결에는 몇 초 걸릴 수 있습니다. **현재색**도 공식 자동에서 시작 시 선택한 색의 도안만 칠합니다. 투명 칸을 건너뛰며, 동일 색 건너뛰기가 켜져 있으면 이미 맞는 칸도 건너뜁니다.
수동 PNG 비교와 분리 캔버스 모드도 사용할 수 있습니다.
